# owly_core

`owly_core` contains Owly's reusable validation and wiki-model logic.

It provides configuration handling, diagnostics, document and link models,
workspace scanning, graph construction, and validation routines used by the
[`owly`](https://crates.io/crates/owly) command-line application.

This is a library building block rather than the primary user-facing package.
Most users should install or depend on `owly` directly.

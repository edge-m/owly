# グラフ境界の移行

OwlyではWikiルートと設定ファイルの組を1つのグラフとして扱います。現在の
ルートから出る相対リンクは外部グラフへのリンクです。対象は存在する外部
グラフの`entrance.md`でなければならず、必須の外部確認は存在確認だけです。

1. 元グラフと外部対象パスを特定し、外部グラフの中身は解決しない。
2. 対象ファイルが存在し、外部グラフの`entrance.md`そのものであることを確認する。
3. 元リンク、解決先、存在結果を報告する。
4. 外部グラフを走査、インデックス化、検証したり、ノードを出力に含めたりしない。
5. グラフ間リンクや入口ページを変更・移動する前に許可を得る。
6. 許可された変更後は元グラフを検証し、外部の存在確認は別に報告する。

この手順には複数グラフの統合設定や統合グラフ出力はありません。グラフ名は
各設定ファイルの`name`に保持します。

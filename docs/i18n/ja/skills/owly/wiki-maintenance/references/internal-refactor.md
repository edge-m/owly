# グラフ内リファクタ

1つのWikiルート内の変更が監査で見つかった場合に使います。最初の調査は
読み取り専用にします。

## 編集前の分類

- 壊れたリンク: 対象パスと、現在のファイルからの相対パスとして正しいか確認する。
- 孤立・到達不能ページ: 意図的な末端ページやアーカイブでないことを確認する。
- 重複概念: タイトルだけで決めず、タイトル、フロントマター、被リンク、本文を比較する。
- 不足している関係: 本文に根拠がある場合だけリンクを追加し、推測でリンクを増やさない。

## 変更手順

1. 候補と、リンク、移動、統合、アーカイブの変更案を示す。
2. 書き込みの明示的な許可を得る。統合・削除では対象と移動先のパスも確定する。
3. 設定されたフロントマターと必須の`entrance.md`を維持する。
4. 変更後に`owly validate --details --format json`と`owly graph`を実行する。
5. 未解決参照と、到達性が変わったページを報告する。

意味を変える可能性がある場合は、書式統一のために全ページを書き換えず、判断を求めます。
